# 源码目录

按实际技术栈在此展开。约定：

- 一个模块一个子目录，目录名用小写连字符，例如 `src/voice-input/`。
- 对外接口集中在 `src/<模块>/index.*`，便于其他模块引用。
- 业务逻辑与框架代码分开：可测试的纯逻辑不要和 UI / 路由混在一个文件里。
- 不要在此放构建产物、模型权重、数据集（见根目录 `.gitignore`）。

典型结构示例（请按实际选型替换）：

```text
src/
├── app/            # 应用入口与路由
├── modules/        # 业务模块
├── lib/            # 通用工具与适配层
└── types/          # 类型定义
```
