# 03 · 评审对照表

> 作用：把赛题的每一个评分维度，直接映射到仓库里的一块代码 / 一段演示。评审不需要猜，我们也不漏项。
>
> 用法：把赛题评分表逐行抄进「评分维度」，每完成一项就补上证据位置与状态。

## 五、评审常见追问与我们的回答

提前准备好答案，现场就不会结巴：

1. **「这个和已有的 X 有什么不同？」** → 待填写
2. **「数据从哪里来？合规吗？」** → 待填写
3. **「如果我一个人用，成本是多少？」** → 待填写
4. **「这套东西能扛住多大流量？」** → 待填写
5. **「如果现在给你一周，你会先改哪里？」** → 待填写
