# 动态角色画像

> 目标：每个角色都有符合年龄、身份与经历的动态画像，动漫悬疑风格，特征明确。

## 1. 实现方式

- 组件：`src/components/character/CharacterPortrait.tsx`
- 画像配置：`src/components/character/portraitProfile.ts`
- 使用 SVG 绘制，不依赖外部图片或新依赖
- 头像在角色卡与角色档案中复用

## 2. 角色特征映射

画像从角色的 `name`、`identity`、`age` 推导：

| 身份关键词 | 造型特征 |
| --- | --- |
| 管家 | 深色西装、领带、后梳发型、克制表情 |
| 医生 | 白大褂、听诊器、眼镜、疲惫眼神 |
| 律师 | 深色西装、领带、侧分发型、锐利眉形 |
| 画家 | 画家围巾/罩衫、凌乱头发、柔和表情 |
| 侦探 | 风衣、帽子、锐利眼神 |
| 女仆 / 佣人 | 女仆头饰、围裙、盘发 |
| 新娘 | 头纱、浅色礼服、温柔表情 |
| 新郎 | 西装、领带、沉稳表情 |
| 伴娘 | 波浪发、发饰、礼服 |
| 婚礼策划 | 马甲/西装、领带、精干表情 |
| 继承人 | 深色外套、侧分发型、略带心事的眼神 |
| 民俗学者 | 眼镜、盘发/书卷气 |
| 守钟人 | 帽子、提灯、年长面部线条 |
| 古董商 | 单片眼镜、深色外套 |
| 列车长 | 制服帽、深色制服 |
| 记者 | 相机、风衣、锐利眼神 |
| 乘务员 | 制服帽、盘发 |
| 商人 | 西装、单片眼镜、精明表情 |
| 学生 | 学院风、书本、清亮眼神 |

年龄会影响脸型、眼角/嘴角细纹和青春感；不同角色还会根据姓名哈希得到不同的发色、瞳色、肤色、痣/疤痕/雀斑、耳饰等细节。

## 3. 动效

在 `src/styles/theme.css` 中定义：

- `portrait-breathe`：轻微呼吸起伏
- `portrait-blink`：随机感眨眼
- `portrait-hair`：发丝轻微摆动
- `portrait-glow`：背景光晕呼吸
- `portrait-flicker`：提灯/火光闪烁

支持 `prefers-reduced-motion: reduce`，用户关闭动效时自动静止。

## 4. 使用位置

- `CharacterCard`：剧本详情的角色列表
- `CharacterSheet`：角色档案大图
