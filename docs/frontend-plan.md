## 9. Skill 组合与可探索房间（新增）

前端优先使用这三个 Skill：

1. `frontend-app-builder`：从视觉概念到 React 页面实现的主力
2. `frontend-design`：复古悬疑、手绘、非 SaaS 化视觉指导
3. `frontend-testing-debugging`：动画、交互、响应式与视觉回归检查

下一阶段新增「可探索房间」：

```text
进入房间
 → 点击油画 / 书桌 / 壁炉 / 钟楼窗
 → 物件动效 + 线索弹窗
 → 记入我的线索
 → AI DM 对话
 → 解锁下一处场景
```

实现与验收细节见 `docs/interactive-room.md`。
